* Roded

Roded is a programmable editor and Ruby development environment. The core
owns document text, edit history, buffers, editor windows, and cursor positions.
The curses and Qt frontends present and route input to that shared core.

* Implemented in the first working version

- Curses terminal UI and Qt desktop UI on Linux.
- Multiple file buffers, independent editor windows, and horizontal or vertical
  splits. Two windows can show one document with independent cursor positions.
- Text editing, undo/redo, region operations, line and text search, query replace,
  safe file save flows, and configurable key bindings.
- File, buffer, command, line, project-file, and kill-ring pickers.
- Ruby, JSON, YAML, and Markdown syntax highlighting, with plain text fallback.
- An in-process Ruby REPL that can inspect and change editor state through the
  core event loop.
- Mouse selection, wheel scrolling, and system clipboard support in Qt.

See `../README.md` for startup and common commands, `keybindings.md` for the
binding reference, `qt-frontend.md` for Qt development notes, and
`working-editor-validation.md` for tested versions, commands, and observations.

* Roadmap and exclusions

The longer-term direction is a Ruby-scriptable development environment with
additional tools and integrations. Those goals are not claims about the current
release. LSP, collaboration, debugging, Magit, web frontends, Vim/Evil modes,
structural editing, folding, external formatting, and a general plugin framework
are outside the first working version.
